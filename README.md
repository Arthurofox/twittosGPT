## Streamlit secrets

Set the OpenAI key in Streamlit Cloud under:

`App settings` -> `Secrets`

Use this exact secret name:

```toml
OPENAI_API_KEY = "sk-proj-your-key-here"
```

Do not commit a real API key to this public repository.
